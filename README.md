# ia_knowledge

Wiki d’aprenentatge progressiu sobre intel·ligència artificial, aprenentatge automàtic, models de llenguatge i sistemes de coneixement.

## Estructura

- 0. Raw/ — fonts originals.
- 1. Wiki/ — autors, conceptes i models.
- 2. Skills/ — ingesta, actualització i auditoria.
- 3. Dashboards/ — consultes per a Obsidian.
- 4. Templates/ — plantilles i documents de suport.

## Flux

0. Raw/ → lectura i classificació → 1. Wiki/ → índex, dashboards i registre.
