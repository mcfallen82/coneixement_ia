# 0.2.

Altres fonts originals i materials d’aprenentatge que encara no tenen una categoria específica.

## Quan utilitzar-la

És adequada per a tutorials, guies pràctiques, documentació oficial, notes de projectes, transcripcions i materials mixtos.

Quan un tipus de font adquireixi prou volum, es pot crear una subcarpeta específica sense alterar el flux general.

## Processament

Conserva l’origen i l’estat de cada document. Després de llegir-lo, extreu conceptes, models, autors i preguntes; comprova si ja existeixen fitxes equivalents; crea o actualitza les pàgines de 1. Wiki/; i registra el resultat a .manifest.json i log.md.

Consulta [[2. Skills/wiki-ingest]] per aplicar el procediment complet.
