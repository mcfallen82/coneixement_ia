# 0.1. llibres

Llibres, plans de lectura i materials extensos sobre intel·ligència artificial, aprenentatge automàtic, models de llenguatge i camps relacionats.

La [[0. Raw/0.1. llibres/Taula_Lectures]] és un pla de lectura consultable amb Obsidian. Les seves entrades es transformen progressivament en fitxes amb [[2. Skills/wiki-ingest]], mantenint la font a sources.

Quan sigui possible, cada font ha de conservar títol, autor, any, editor o URL i estat de lectura.
