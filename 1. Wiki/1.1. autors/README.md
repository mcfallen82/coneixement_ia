# 👥 Autors — les persones darrere de les idees

## Qui hi trobaràs i com consultar aquesta carpeta

Aquesta carpeta reuneix fitxes permanents d'investigadors, divulgadors i altres referents relacionats amb la intel·ligència artificial o els sistemes de coneixement. Ajuda a entendre **qui ha proposat una idea, en quin context i mitjançant quina obra o projecte**. Per exemple, la fitxa d'[Andrej Karpathy](Karpathy,%20Andrej.md) connecta els seus materials amb conceptes i models tractats a la wiki.

Les persones són punts de connexió entre fonts i idees, no una classificació del prestigi dels autors. Les fitxes han de distingir aportacions documentades, explicacions posteriors i interpretacions de la wiki.

## 🗂️ Què conté una fitxa d'autor?

- **Identificació i àmbit:** nom, camps de treball i context necessari per situar-lo.
- **Obres i aportacions:** publicacions, recursos o projectes rellevants per al contingut de la wiki.
- **Relacions:** enllaços a [conceptes](../1.2.%20conceptes/), [models](../1.3.%20models/) i, quan escau, [llibres](../1.4.%20llibres/).
- **Procedència:** fonts verificables que sustenten les afirmacions. Les afiliacions, dates o atribucions només s'han de consignar si es poden comprovar.

## 🧭 Com utilitzar les fitxes

Si parteixes d'un nom, obre'n la fitxa i segueix les relacions per arribar a les idees corresponents. Si parteixes d'un model o un llibre, consulta els autors enllaçats per identificar contribucions i altres obres. El [README de la wiki](../README.md) explica el recorregut entre les quatre categories i l'[índex general](../../index.md) permet explorar el projecte sencer.

## ✍️ Com afegir o revisar un autor

1. Busca el nom i les variants de signatura per evitar duplicats; comprova que la persona sigui realment rellevant per a una fitxa existent o una font estudiada.
2. Usa la [plantilla d'autor](../../4.%20Templates/90.1.%20templates_fitxes/plantilla_autor.md) i els camps obligatoris del frontmatter definits a [`AGENTS.md`](../../AGENTS.md).
3. Explica l'aportació amb fonts concretes i afegeix enllaços a les fitxes relacionades; revisa els camps `author` o `authors` a les peces que correspongui, sense atribuir coautories per inferència.
4. Mantén la fitxa llegible de manera independent i comprova els enllaços i la procedència abans de proposar el canvi.
