# 1.3. models

Fitxes sobre arquitectures, models, famílies de models, models multimodals i models generatius.

## Criteri mínim

Cada fitxa de model ha d’explicar:

- quin problema resol;
- família i arquitectura;
- modalitats d’entrada i sortida;
- objectiu d’entrenament i dades, quan siguin coneguts;
- conceptes de 1. Wiki/1.2. conceptes que cal entendre;
- punts forts, limitacions i aplicacions;
- models relacionats i fonts verificables.

El frontmatter ha d’utilitzar, quan sigui aplicable, title, category, model_family, architecture, modalities, training_objective, sources, related_concepts, related_models, status, created i updated. La plantilla corresponent és [[4. Templates/90.1. templates_fitxes/plantilla_model]].
