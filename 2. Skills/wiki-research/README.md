# wiki-research

Skill per fer recerca externa en diverses rondes i convertir-ne el resultat en coneixement verificable de `coneixement_ia`.

## Quan utilitzar-la

Quan cal investigar, ampliar o contrastar un tema, o quan una fitxa té fonts insuficients.

## Què fa

1. defineix la pregunta i els angles de recerca;
2. prioritza papers, documentació i repositoris oficials;
3. identifica buits, contradiccions i afirmacions febles;
4. decideix quines fitxes crear o actualitzar;
5. registra URLs, referències i confiança;
6. valida la integració final amb `wiki-lint`.

La recerca no consisteix a acumular enllaços: ha de produir una síntesi útil, separar fets d'inferències i deixar clara la procedència.

## Resultat esperat

Fonts externes verificables, fitxes noves o actualitzades, connexions i un informe dels buits pendents.
