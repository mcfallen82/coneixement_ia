# wiki-capture

## Finalitat

Convertir una conversa, decisió o descobriment en una nota permanent útil.

## Protocol

1. Identifica què mereix conservar-se: una idea, una decisió, un procediment, un error o una síntesi.
2. Classifica-ho com autor, concepte, model o font.
3. Reescriu-ho com a coneixement declaratiu, no com una transcripció.
4. Conserva el context necessari i elimina el diàleg irrellevant.
5. Afegeix fonts i marca clarament les inferències.
6. Cerca fitxes existents abans de crear-ne una.
7. Actualitza fitxa, índex, registre, hot i manifest.

## Estructura per a una idea

~~~markdown
# Títol

## Context
## Idea o decisió
## Raonament
## Implicacions
## Relacions
## Fonts
~~~

Si el contingut és provisional, utilitza status draft i afegeix preguntes obertes. No converteixis una opinió temporal en un fet consolidat.
