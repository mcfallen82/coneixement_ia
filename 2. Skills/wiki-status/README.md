# wiki-status

Skill de diagnòstic per obtenir una fotografia ràpida de l'estat del projecte.

## Quan utilitzar-la

Quan es vol saber què s'ha actualitzat, què continua pendent i on hi ha deute de cobertura o qualitat.

## Què revisa

- fonts externes registrades al manifest i el seu estat de processament;
- fitxes recents o en `draft`;
- fitxes sense `sources` o amb poques connexions;
- coherència entre dates de les fitxes i `log.md`;
- pendents i prioritats següents.

## Resultat esperat

Un informe d'estat amb fonts pendents, fitxes incompletes, relacions febles i prioritats. La skill és de diagnòstic: no considera processada una font només perquè estigui registrada.
