# wiki-export

Skill per convertir les fitxes i relacions de `coneixement_ia` en formats reutilitzables fora del repositori.

## Quan utilitzar-la

Quan es vulgui analitzar la xarxa amb altres eines, crear una representació de graf o obtenir una versió resumida i portable del coneixement.

## Què fa

- converteix cada fitxa en un node amb metadades;
- extreu wikilinks i relacions estructurades;
- pot generar JSON, GraphML o Markdown resumit;
- conserva procedència i delimita explícitament l'abast exportat;
- no incorpora automàticament materials externs originals.

## Resultat esperat

Una exportació reproduïble del coneixement propi de la wiki, separada de les fonts externes que el sustenten.
