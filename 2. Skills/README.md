# 2. Skills

Procediments reutilitzables per estudiar, mantenir i consultar la wiki d’aprenentatge d’IA.

- [[2. Skills/wiki-ingest]] — incorpora fonts i en transforma les idees útils en fitxes.
- [[2. Skills/wiki-update]] — actualitza fitxes, conserva fonts i resol duplicats.
- [[2. Skills/wiki-lint]] — audita YAML, estructura, fonts i enllaços.

Les skills descriuen procediments operatius. La governança continua definida exclusivament a [[AGENTS]]. Cada operació d’ingesta o actualització s’ha de registrar a log.md i .manifest.json.
