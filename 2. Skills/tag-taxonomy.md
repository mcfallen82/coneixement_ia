# tag-taxonomy

## Finalitat

Mantenir una vocabulari controlat d’etiquetes perquè les cerques i els quadres de comandament siguin fiables.

## Regles

- utilitza minúscules i guions;
- limita les etiquetes a les necessàries;
- no creïs variants ortogràfiques per al mateix tema;
- separa tags de domini, tipus i estat;
- no utilitzis tags per substituir wikilinks.

## Procés d’auditoria

1. Extreu les etiquetes de les fitxes de 1. Wiki/.
2. Agrupa variants semblants.
3. Detecta etiquetes desconegudes, massa àmplies o duplicades.
4. Proposa una forma canònica.
5. Aplica normalitzacions mecàniques després de revisar el significat.
6. Registra canvis al log.md.

Les etiquetes no substitueixen category, sources, related_concepts o related_models.
