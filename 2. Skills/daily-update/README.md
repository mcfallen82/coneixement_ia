# daily-update

Skill de manteniment periòdic. Serveix per revisar si hi ha fonts, fitxes o registres que necessiten actualització i per resumir les prioritats següents.

## Quan utilitzar-la

Quan es vulgui fer una revisió regular del projecte després d'haver incorporat noves fonts, fitxes o canvis estructurals.

## Què fa

- revisa fonts externes registrades i pendents del manifest;
- identifica fitxes noves, modificades o incompletes;
- activa `wiki-ingest` o `wiki-update` quan correspon;
- sincronitza els fitxers de control;
- executa `wiki-lint` i resumeix incidències.

## Resultat esperat

Un informe breu de manteniment amb canvis processats, problemes detectats i prioritats. Si no hi ha novetats, la skill no força modificacions artificials.
