# wiki-update

Skill per sincronitzar informació nova amb fitxes permanents ja existents.

## Quan utilitzar-la

Quan una nova font, versió d'un projecte o descobriment amplia, corregeix o matisa coneixement que la wiki ja conté.

## Què fa

- compara informació nova i existent;
- separa dades, correccions, contradiccions i exemples;
- conserva contingut vàlid, fonts i data de creació;
- actualitza `sources`, relacions i data `updated`;
- prefereix ampliar una fitxa existent abans de crear duplicats;
- valida el resultat i actualitza els registres quan correspon.

## Resultat esperat

Una fitxa actualitzada que conserva la seva història conceptual i incorpora la nova evidència de manera traçable.
