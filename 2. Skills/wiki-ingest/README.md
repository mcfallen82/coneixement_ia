# wiki-ingest

Skill principal per transformar una **font externa** en coneixement permanent, traçable i connectat dins de `coneixement_ia`.

## Quan utilitzar-la

Quan s'ha llegit o seleccionat un article, paper, llibre, vídeo, documentació, repositori, conversa o conjunt de dades i se'n vol incorporar el coneixement útil a la wiki.

## Què fa

- registra la font mitjançant URL o referència bibliogràfica;
- extreu conceptes, models, autors, exemples i limitacions;
- comprova si ja existeixen fitxes relacionades;
- decideix entre crear, actualitzar, enllaçar o només registrar la font;
- afegeix `sources`, wikilinks i traçabilitat;
- valida el resultat amb `wiki-lint`.

## Resultat esperat

Coneixement propi i sintetitzat dins de `1. Wiki/`, no una còpia del material original.
