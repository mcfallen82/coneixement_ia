# cross-linker

Skill per detectar i afegir connexions significatives entre autors, conceptes, models, llibres i fonts.

## Quan utilitzar-la

Després de crear o actualitzar fitxes, o quan una zona de la wiki conté informació correcta però poc connectada.

## Què fa

- busca mencions i relacions semàntiques entre fitxes existents;
- proposa wikilinks només quan aporten context o recuperació útil;
- revisa relacions estructurals en ambdues direccions quan és pertinent;
- evita omplir les pàgines d'enllaços decoratius.

## Resultat esperat

Una xarxa de coneixement més navegable, amb cada connexió justificable pel significat de les fitxes.
