# wiki-synthesize

Skill per crear coneixement transversal a partir de diverses fitxes existents, quan considerar-les conjuntament aporta una conclusió nova.

## Quan utilitzar-la

Quan dues o més idees estan relacionades però la connexió important encara no està explicada explícitament a la wiki.

## Què fa

- compara mecanismes, aplicacions, avantatges, límits i tensions;
- evita repetir relacions que ja estan documentades;
- crea una síntesi només si aporta un insight addicional;
- enllaça la nova idea amb les fitxes d'origen;
- conserva fonts i preguntes obertes.

## Resultat esperat

Una síntesi que explica què s'entén millor gràcies a combinar les idees, no una simple concatenació de resums.
