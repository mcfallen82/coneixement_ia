# wiki-context-pack

Skill de recuperació selectiva. Prepara un paquet petit de context perquè una altra tasca, persona o agent pugui treballar amb la wiki sense llegir-la sencera.

## Quan utilitzar-la

Quan cal concentrar el coneixement rellevant sobre un tema sota un límit de context o tokens.

## Què fa

- defineix un objectiu concret;
- selecciona una fitxa central i el coneixement relacionat;
- conserva rutes, fonts i confiança;
- prioritza informació necessària i exclou fragments irrellevants;
- no crea una nova fitxa permanent llevat que se sol·liciti.

## Resultat esperat

Un paquet de context suficient per actuar, amb procedència i buits explícits.
