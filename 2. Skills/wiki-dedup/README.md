# wiki-dedup

Skill per detectar possibles duplicats entre fitxes i, quan és segur, consolidar-los sense perdre informació ni procedència.

## Quan utilitzar-la

Abans de crear una fitxa nova o durant auditories de qualitat, especialment quan hi ha sinònims, traduccions o grafies alternatives.

## Què fa

- compara títols, tags, fonts, definicions i enllaços;
- classifica candidats segons la confiança;
- identifica una fitxa canònica quan hi ha duplicació real;
- conserva informació i fonts úniques;
- exigeix revisió humana per a fusions o eliminacions amb impacte semàntic.

## Resultat esperat

Menys redundància sense confondre conceptes que només són semblants.
