# wiki-rebuild

Skill de manteniment excepcional per arxivar, reconstruir o restaurar una part de la wiki sense perdre coneixement.

## Quan utilitzar-la

Només quan una reorganització o reconstrucció no es pot resoldre amb una actualització normal.

## Modes

- `archive`: conserva una còpia de seguretat abans d'actuar;
- `rebuild`: reconstrueix l'abast confirmat a partir de fonts i fitxes seleccionades;
- `restore`: recupera una versió anterior després d'arxivar l'estat actual.

## Regles de seguretat

Les operacions destructives requereixen abast explícit, registre i revisió humana. Les còpies temporals o de seguretat no s'han de convertir accidentalment en contingut públic del repositori.

## Resultat esperat

Una wiki coherent després d'una reconstrucció controlada i validada amb `wiki-lint`.
