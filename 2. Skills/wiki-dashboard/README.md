# wiki-dashboard

Skill per crear vistes de seguiment llegibles directament com a Markdown i útils per revisar l'estat de la wiki.

## Quan utilitzar-la

Quan es necessita una vista sintètica de fitxes recents, contingut incomplet, fonts pendents, categories, tags o fitxes orfes.

## Què fa

- defineix dashboards estàtics i comprensibles a GitHub;
- evita dependències obligatòries de Dataview o plugins locals;
- reutilitza camps normalitzats com `title`, `category`, `sources`, `status` i `updated`;
- remet als scripts del projecte quan cal una comprovació dinàmica.

## Resultat esperat

Un dashboard que continua sent útil encara que el lector no utilitzi Obsidian ni cap plugin concret.
