# vault-skill-factory

Skill per convertir un conjunt madur de coneixement de la wiki en un **procediment reutilitzable i especialitzat**.

> El nom de la carpeta és històric. La skill no depèn d'Obsidian ni d'un *vault*: treballa sobre la wiki Markdown del repositori.

## Quan utilitzar-la

Quan diverses fitxes ja contenen prou evidència, criteris i connexions per transformar aquell coneixement en una manera de treball repetible.

## Què fa

- selecciona un conjunt coherent de fitxes;
- n'extreu principis, vocabulari, passos i criteris de qualitat;
- defineix entrades, sortides i validació d'una nova skill;
- contrasta les regles amb les fonts;
- valida l'esborrany abans d'incorporar-lo a `2. Skills/`.

## Resultat esperat

Una skill nova que reutilitza coneixement consolidat sense substituir les regles d'`AGENTS.md`.
