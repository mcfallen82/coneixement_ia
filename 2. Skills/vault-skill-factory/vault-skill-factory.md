# vault-skill-factory

## Finalitat

Convertir un conjunt madur de fitxes de la wiki en una skill reutilitzable i especialitzada.

## Requisits

- les fitxes han de tenir fonts verificables;
- els conceptes han d’estar connectats;
- les contradiccions i limitacions han d’estar documentades;
- el procediment resultant ha de tenir un objectiu clar;
- no s’han d’exposar dades personals o fonts restringides.

## Procés

1. Escull un conjunt coherent de fitxes d’autors, conceptes i models.
2. Extreu vocabulari, principis, passos i criteris de qualitat.
3. Dissenya una skill amb finalitat, àmbit, entrades, procediment, sortides i validació.
4. Contrasta cada regla amb les fonts de la wiki.
5. Desa l’esborrany a 4. Templates/90.2. docs_support/ o a una ubicació de revisió.
6. Valida’l amb impl-validator.
7. Publica’l a 2. Skills/ només després de revisar conflictes amb AGENTS.md.

La skill generada no substitueix la governança del repositori: AGENTS.md continua tenint prioritat.
