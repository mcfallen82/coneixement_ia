# tag-taxonomy

Skill per mantenir un vocabulari d'etiquetes coherent i evitar que la taxonomia es degradi a mesura que creix la wiki.

## Quan utilitzar-la

Quan apareixen tags duplicats, variants ortogràfiques, etiquetes massa àmplies o dificultats per filtrar contingut de manera fiable.

## Què fa

- extreu i agrupa les etiquetes existents;
- detecta variants i duplicats;
- proposa formes canòniques;
- diferencia `tags` de camps estructurals com `category`, `sources` o relacions;
- aplica només normalitzacions que preserven el significat.

## Resultat esperat

Una taxonomia petita, estable i útil per a cerques i dashboards.
