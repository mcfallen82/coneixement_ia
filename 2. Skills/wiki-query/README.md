# wiki-query

Skill de lectura per respondre preguntes utilitzant primer el coneixement ja compilat a `1. Wiki/`.

## Quan utilitzar-la

Quan la pregunta es pot resoldre consultant fitxes, relacions i fonts ja registrades sense necessitat d'escriure al repositori.

## Què fa

- recupera fitxes per títols, tags i relacions;
- segueix wikilinks quan cal context addicional;
- diferencia contingut documentat d'inferències;
- exposa discrepàncies entre fonts;
- identifica buits quan la wiki no conté evidència suficient.

Si cal contrast extern, la consulta remet a les URLs o referències registrades i pot activar `wiki-research`; no depèn de cap carpeta local de fonts.

## Resultat esperat

Una resposta sintètica amb evidència, incerteses i fitxes consultades.
