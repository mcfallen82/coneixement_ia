# wiki-import

Skill per incorporar fitxes i relacions a partir d'un graf exportat o d'un paquet de dades compatible.

## Quan utilitzar-la

Quan informació estructurada creada fora de la wiki s'ha de comparar i integrar amb `1. Wiki/`.

## Què fa

- identifica i valida el format d'entrada;
- comprova categories, títols, identificadors i conflictes;
- permet treballar en modes `dry-run`, `merge` o `overwrite`;
- mapifica nodes i relacions a rutes reals de la wiki;
- protegeix les fitxes existents davant sobreescriptures no revisades.

## Resultat esperat

Una importació traçable que incorpora només informació compatible i revisada.
