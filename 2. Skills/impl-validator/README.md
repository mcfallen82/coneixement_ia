# impl-validator

Skill de verificació funcional: comprova si una reorganització, una fitxa o una altra skill **compleix realment l'objectiu que declara**.

## Quan utilitzar-la

Després d'una modificació significativa i abans de considerar-la acabada.

## Què comprova

- objectiu i abast del canvi;
- estructura i frontmatter;
- coherència del contingut, fonts i relacions;
- resultat de les validacions disponibles;
- diferència entre errors, advertiments i millores opcionals.

## Resultat esperat

Un veredicte `PASS`, `WARN` o `FAIL` justificat. La simple existència d'un fitxer no és suficient: la implementació ha de ser coherent amb `AGENTS.md` i amb el propòsit declarat.
